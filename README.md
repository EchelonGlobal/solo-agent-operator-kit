# The Solo Agent Operator Kit

Hardened workspace templates, a skill-vetting checklist, and a 24/7 operator routine for solo agent runners. So your agent runs with structure instead of vibes.

## Why this exists

You run an AI agent for yourself. OpenClaw, Claude Code, OpenCode, something like that. It has your email, your calendar, your files. You install community skills. And nobody ever taught you how to run the operation around it with discipline.

In February 2026, 341 of 2,857 ClawHub skills were found malicious (infostealers, reverse shells, the Atomic macOS stealer), and the count doubled in 15 days ([thehackernews.com](https://thehackernews.com), Feb 2026). Snyk found flaws in 36% of the skills they scanned. The free scanners are real tools, but they are reactive, and they have been evaded. This kit is the operating system around the scanners.

## What's inside the full kit (37 files)

1. **Hardened starter workspace** — AGENTS, SOUL, USER, TOOLS, MEMORY, and BOOT templates with fill-in blanks, a never-commit-a-secret rules file, and a vault gitignore.
2. **Skill verification playbook** — a 12-point before-install checklist, a monthly re-scan cadence with integrity-hash pinning, and a plain-language red-flags gallery drawn from real malicious-skill findings.
3. **The operator loop system** — standing-orders template, 24-hour schedule blocks, a one-item priority rule, cron starter set, and an incident playbook: quarantine, revoke, rotate secrets.
4. **Ledgers and audit trail** — hours and experiment ledger templates, a daily log format with every factual claim tagged, and an approval-card template for operator-gated actions.
5. **Disclosure pack** — AI-production disclosure templates for product pages, directory listings, and agent-built services.

Plus the cautionary page — the author's own account of working with a model through heavy hallucinations, and the one distinction that matters: mistakes are fine; building on undisclosed synthetic information is not.

**What this is not:** not a security scanner (it works alongside the free scanners, it does not replace them). Not enterprise compliance. Not legal advice.
