# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

If you find a security issue in this repository, please report it privately. Do not open a public issue for a live vulnerability.

Contact: fcarrasco@echelonls.com

Please include:

- A clear description of the issue
- Steps to reproduce it
- Any files or configurations involved

We will acknowledge your report within 5 business days and work with you on a fix before anything is disclosed publicly. Thank you for helping keep this project safe.

## Scope

This repository holds templates and documentation. It shares operational best practice, not a security product, and following it does not make your setup invulnerable. It is not legal advice.
